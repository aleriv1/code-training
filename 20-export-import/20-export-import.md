Цель урока:

1.  Узнать, что такое import и export
2.  Разобраться, как они помогают разделять функциональность проекта на разные файлы и переносить сущности из одного файла в другой
3.  Научиться использовать import и export на практике

Содержание урока:

1.  Использование import, export, export default. Реализация структуры проекта
2.  Разработка класса JSBlock. Работа с import и export
3.  Разработка класса TimerBlock. Работа с import и export
4.  Реализация вспомогательных функций. Работа с import \* 
5.  Внесение последних правок в проект
