Типы данных в JavaScript

В предыдущем уроке мы узнали, как создавать переменные. Мы работали со строковыми переменными, но как и в любом языке программирования, в JavaScript есть целый набор типов данных. Каждый из типов имеет своё предназначение и особенности использования.

Всего в JavaScript существует 8 типов данных:

String
Number
Boolean
Null
Undefined
Object
Symbol
BigInt
Рассмотрим каждый из этих типов данных и нюансы работы с ними подробнее.

String

String — это тип данных для хранения строковых значений. Мы уже успели поработать с этим типом данных в предыдущих уроках.

По сути, строка — это набор букв и других символов, заключенных в кавычки. Для строк в JavaScript можно использовать кавычки трёх видов:

Одинарные
Двойные
Косые
Создадим три строковые переменные, используя все эти виды кавычек:

<script>
  let string1 = 'Одинарные';
  let string2 = "Двойные";
  let string3 = `Косые`;
  let string1 = 'Одинарные';
  let string2 = "Двойные";
  let string3 = `Косые`;
</script>

Обратите внимание, что тип открывающих и закрывающих кавычек для одной переменной должен совпадать.

Чтобы использовать кавычки внутри строки, нужно использовать кавычки другого типа, либо поставить обратный слэш перед кавычками внутри строки (\"). Например:

<script>
  let correct1 = 'Я прохожу курс "База JavaScript"';
  let correct2 = "Я прохожу курс \"База JavaScript\"";
  // В обеих переменных будет: Я прохожу курс "База JavaScript"
  
  // Неправильно, выполнение кода приведет к ошибке
  let incorrect = "Я прохожу курс "База JavaScript"";
</script>

Более подробно работу со строками мы рассмотрим в одном из следующих уроков.

Number

Number — это тип данных для хранения чисел. Он используется как для целых, так и для дробных чисел:

<script>
  let age = 23;
  let weight = 67.5;
  let temperature = -5;
</script>

Зачастую вы будете использовать различные математические операции с числовыми переменными, например:

<script>
  let a = 2;
  let b = 3;
  console.log(a + b); // В консоль будет выведено значение 5
</script>

Более подробно с математическими операциями мы познакомимся в отдельном уроке.

BigInt

BigInt — используется для хранения очень больших целых чисел (больше, чем (2⁵³-1), т.е. 9007199254740991).

Для создания переменной этого типа нужно поставить букву n в конце числа:

let bigNumber = 123456789n;
Boolean

Boolean — это логический (булевый) тип данных. Переменная этого типа может иметь всего два значения:

true (истина)
false (ложь)
Такие переменные часто используются в коде для проверки каких-либо условий либо когда необходимо хранить какой-либо флаг или признак:

<script>
  let carName = "Porsche 911";
  let isSuperCar = true; // Логическое значение "истина"
</script>

Null

Null — специальный тип данных для хранения пустого или неизвестного значения:

// У нас была машина
let myCarName = "Toyota Corolla";

// Но потом мы её продали и остались без машины
myCarName = null;
Undefined

Undefined — ещё один специальный тип данных. Он показывает, что переменная была объявлена, но значение ей не присвоено.

Попробуем объявить переменную без присвоения значения и вывести её на консоль:

let x;
console.log(x); // Выведет undefined
В чем же отличие от Null? В случае с Null известно, что переменной уже присвоено значение. Undefined же говорит о том, что переменная объявлена, но никакого значения ей не было присвоено.

На практике не рекомендуется вручную задавать значение undefined какой-либо переменной. Если нужно явно задать пустое значение, используйте значение null.

Object

Object — это сложный тип данных, который позволяет объединить несколько схожих параметров в одну сущность или структуру.

Объект объявляется с помощью фигурных скобок, внутри которых следует список пар «ключ: значение»:

<script>
  const car = {
    name: "Toyota Corolla",
    year: 2017,
    isNew: false,
    owner: null
  }
</script>

В этом примере мы создали объект «машина» и задали ему свойства различных типов:

name — название (string)
year — год выпуска (number)
isNew — признак, новая ли машина (boolean)
owner — владелец (null)
Объект можно представить как большую коробку, в которую помещаются более мелкие коробки (свойства):

Забегая вперед скажем, что обратиться к свойству объекта можно через точку:

console.log(car.name);
Объекты — это очень важная и обширная тема, которой будет посвящен отдельный урок.

Symbol

Symbol — используется для создания уникальных ключей объекта.

Для создания переменных этого типа существует специальная одноименная функция:

<script>const id = Symbol("id");</script>

С Symbol мы поработаем в уроке по объектам.

Определение типа данных

В JavaScript существует специальный оператор typeof, который позволяет определить тип данных любой переменной. При этом возвращается строка с названием типа данных, например "number".
Есть две формы записи typeof, со скобками и без них. Они равнозначны и можно использовать ту, которая кажется тебе удобнее:

<script>
  typeof(x);
  typeof x;
</script>

Попробуем вывести на консоль тип данных нескольких переменных (в комментарии указано значение, которое будет выведено на консоль):

<script>
  console.log(typeof "Строка"); // string
  console.log(typeof 7); // number
  console.log(typeof {}); // object
</script>

В большинстве случаев оператор typeof работает предсказуемо и выводит тот тип, который мы ожидаем увидеть. Однако существует два исключения:

// Исключения в работе typeof

<script>
  console.log(typeof null); // object
  console.log(typeof alert); // function
</script>

Для значения null существует специальный одноименный тип, однако typeof возвращает значение "object". Это давно известная ошибка, которую не исправляют для совместимости с существующим кодом.

Вызов typeof alert (напомним, что alert() является встроенной функцией) возвращает значение "function", хотя такого типа данных нет. Сделано это специально и иногда пригождается на практике.
